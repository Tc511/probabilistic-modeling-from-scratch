# Probabilistic modeling from scratch

目标：只给定观测数据，学习概率生成模型。每章改变一个主要建模条件，观察原来的边缘化和 MLE 方法能否继续使用。

## 环境搭建

```bash
uv sync --locked
```

在仓库根目录启动 Jupyter，按编号运行（CPU 即可）。第 01–05 章的整数编号章节使用相同的二维观测数据；第 04.5 章使用独立的非高斯模型；真实生成类别不参与训练。第 06–07 章因增加时间结构而重新生成数据，第 06.5 章独立复现第 06 章的数据生成方式。第 05 章优先读取第 04 章保存的模型，也可独立运行。

## 主线

先定义概率模型，再计算联合密度与观测边缘密度，最后最大化观测对数似然。第 06 章暂时固定模型参数，单独研究状态推断；第 06.5 章恢复参数学习。在时序模型中，滤波后验也是递推计算观测似然的中间量。

| 章 | 相对上一相关章节的变化 | 边缘化与学习方式 |
|---|---|---|
| 01 | 无隐变量 | 直接定义观测分布；MLE 有解析参数解 |
| 02 | 引入离散隐变量 | 有限求和；直接梯度 MLE |
| 03 | 隐变量连续，条件均值为线性函数 | 积分；先用网格验证解析边缘，再沿用梯度 MLE |
| 04 | 线性函数替换为神经网络 | 一般无解析边缘；沿用网格积分和梯度 MLE |
| 04.5 | 固定模型，比较密度求值与高维积分 | 均匀先验、伯努利条件分布；解析积分与先验采样的误差比较 |
| 05 | 添加近似后验网络 | 生成模型不变；以可采样估计的 ELBO 替代直接边缘似然 |
| 06 | 回到 02，增加离散状态时间依赖，固定模型参数 | 逐时间步有限求和；贝叶斯滤波计算状态后验 |
| 06.5 | 撤销转移矩阵和观测模型参数已知的假设 | 滤波计算序列似然；先单参数网格搜索，再联合梯度 MLE，最后固定参数推断 |
| 07 | 将 06 的离散状态换成 03 的连续线性高斯结构 | 解析高斯递推；卡尔曼滤波计算序列似然，再 MLE |

后续可扩展到非线性概率状态空间模型与 PlaNet。

代码使用显式循环、中间变量、矩阵运算和对数概率计算。对连续密度的直接乘积与有限网格积分均有浮点精度或截断限制。

## 代码组织

`utils.py` 保存共享的合成观测数据生成、散点图对比、训练曲线和似然曲线绘图。第 01、02、03、04、05 章通过相同随机种子生成相同数据。第 06–07 章的时序仿真，以及各章的模型定义、概率计算、学习和生成过程仍保留在 Notebook 中。

## 代码阅读原则：数学与代码的通用语言

本项目的目标不是最快训练，而是为后续阅读论文建立简单、直观、可执行的数学对应物。借鉴 DDD 的通用语言思想，理论、注释、代码使用同一套概念；每个额外的编程概念都必须有当前必要性。优先让读者看清单条观测、单个隐变量、一个数学操作，再展示批量版本。理论主线不依赖技巧版本。

| 数学 | 代码语义 |
|---|---|
| 先验、条件、联合、边缘、后验 | prior, conditional, joint, marginal, posterior |
| 点的对数密度/质量 | log_prob |
| 期望 | 显式积分或采样求平均 |
| 近似后验、变分下界 | q, elbo |

分布对象/函数是完整描述，调用 log_prob 或 pdf 才是在给定点求值。单点密度不是概率。离散变量求和，连续变量积分。只在必须处理数值下溢、参数约束、梯度或不可接受的运行开销时引入技巧，并在首次使用处说明原因、对应公式和维度。

先定义概率分布，再展示具体点的密度求值、边缘化与训练目标。优先使用显式循环与数学公式对应；批量计算只在训练中避免大量重复计算图，并说明形状和归约维度。数值稳定操作（logsumexp、log-softmax）与梯度技巧（rsample）需说明用途。第 05 章直接采样计算 ELBO 的三项对数密度，解析 KL 仅作为可选对照。推断时固定当前生成参数，学习时优化生成参数；两者不是同一个任务。
