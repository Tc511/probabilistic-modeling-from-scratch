# Probabilistic modeling from scratch

一个二维生成任务，逐步改变模型结构，观察哪些概率量可以直接计算，哪些需要积分或近似。仅用合成数据。

## 运行

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```

按编号运行 Notebook（CPU 即可）。第 05 章可独立运行，也可读取第 04 章的模型。所有训练均使用观测坐标，不使用真实隐变量标签。

| Notebook | 核心变化 | 知识点 |
|---|---|---|
| 01 | 无隐变量 | 生成、MLE |
| 02 | 离散隐变量 | 联合、边缘、后验、EM |
| 03 | 连续线性隐变量 | 解析边缘化与后验 |
| 04 | 非线性解码器 | 数值积分、直接 MLE |
| 05 | 近似后验网络 | ELBO、变分推断、VAE |
| 06 | 离散状态加入时间依赖 | 贝叶斯滤波、序列似然 |
| 07 | 连续线性高斯时序 | 卡尔曼滤波、观测 MLE |

后续扩展：非线性概率状态空间模型、PlaNet。当前不引入卡尔曼平滑。

注意：每个模型的分布是建模假设，并非真实数据分布已知。给定参数后能逐点计算密度，与能积分或优化该密度是不同的能力。
